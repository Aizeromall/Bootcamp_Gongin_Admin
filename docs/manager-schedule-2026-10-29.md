# 담당 구장 일정과 팀경기매치

작성 일 : 2026-10-29 / 작업자 : 양태건

## 화면 구성

- 매니저 메뉴는 `내 매치 / 지난 매치 / 내 평가`입니다.
- `내 매치`: 선택 날짜의 예정 상태 실력매칭·팀매칭을 하나의 목록으로 표시합니다.
- `지난 매치`: `완료 매치 / 담당 구장 취소`만 제공합니다. 기존 `완료 경기`와 `매치 목록`은 하나의 완료 목록으로 통합했습니다.
- 두 매치 목록 모두 `전체 / 실력매칭 / 팀매칭` 필터, 날짜 선택, 담당 구장 필터, 새로고침을 제공합니다.
- 실력매칭은 `/match/operations`의 `completed`만 지난 매치에 포함합니다. 내 매치는 `attendance`, `teams`만 표시하며 진행 중·결과 확인은 포함하지 않습니다.
- 팀매칭은 상세의 `finished`만 지난 매치, `scheduled`만 내 매치에 포함합니다. `waiting_result`를 완료로 처리하지 않습니다.
- 실력매칭 운영 응답에 팀 경기와 같은 구장·시간이 포함되면 중복으로 표시하지 않습니다.
- 선택한 실력매칭에서 출석·경기 운영 또는 기존 결과 상세를 열 수 있습니다. 등록 성공 후 목록을 갱신하고 지난 매치로 이동합니다.
- 필터·날짜·구장 변경 시 상세 선택을 초기화합니다. 좁은 화면에서 목록 복귀를 제공합니다.
- 개인 기록이 없는 팀 경기 조회 응답에 더미 기록 표를 추가하지 않습니다.

## API 매핑

`GET /match/schedule/{m_id}?r_date=YYYY-MM-DD`

- 경로의 매니저 ID는 로그인 세션을 사용합니다.
- 서버가 assign의 요일·시간·최근 배정 우선순위로 담당 시간대를 계산합니다.
- grounds[].slots[]의 slot_type과 team_match.team_code를 사용합니다.
- `24:00` 종료 시간을 문자열 그대로 보존합니다.
- 팀 상세는 일정의 구장·시작 시간·경기 코드가 일치한 경우에만 `GET /match/team_match/{team_code}`로 조회합니다.
- 전체 팀 경기 목록 `/match/team_match`를 매니저 화면에서 호출하지 않습니다.

## 상태와 권한의 한계

프론트는 로그인한 매니저만 자신의 일정 provider를 사용할 수 있게 하고, 날짜·계정·선택 시간대별로 상태를 분리합니다. 날짜·구장 변경 시 상세 선택을 초기화하며 일정에 없는 코드의 상세 요청은 보내지 않습니다.

그러나 현재 서버의 일정 경로는 전달받은 m_id 기준으로 조회하며 토큰 기반 소유자 검증이 없습니다. 팀 상세 API도 독립적인 담당자 검증이 없습니다. 이번 프론트 연결을 서버의 접근 제어 보완으로 설명하지 않습니다. Python과 실제 DB는 변경하지 않았습니다.

이 API는 날짜별 현재 배정 기준 조회입니다. 모든 기간의 팀 경기 이력을 한 번에 조회하거나 과거 담당 배정 이력을 보장하는 기능은 아닙니다. 경기 운영·기록·결과 등록은 기존 `/match/operations` 경로를 유지하며 일정 시간대에서 임의로 새 경기를 생성하지 않습니다.

## 검증

MockClient와 provider override로 담당 일정의 팀 경기 필터, 실제 경기 코드 상세, 날짜 변경 후 선택 초기화, 빈 결과, 오류 재시도, 계정 전환, 담당 일정에 없는 코드 차단, 늦은 응답 분리를 검증합니다. 작은 화면의 복귀와 넘침도 위젯 테스트로 확인합니다.

실제 API·DB에는 접근하지 않았으며 실기기 연동은 미검증입니다.

통합 변경 검증: 전체 Flutter 테스트 76개 통과. 통합 목록·종류 필터·선택 초기화·불필요한 재조회 방지·메뉴 제거·기존 경기 운영 흐름을 Mock으로 검증했습니다. 정적 분석은 기존 이름 규칙 안내 35개만 남아 있습니다.

후속 배치 변경: 사용자 선택에 따라 매치 목록을 지난 매치로 옮겼습니다. 이 목록은 날짜별 일정 API를 그대로 사용하므로 메뉴 위치만으로 경기 완료 여부를 판단하거나 예정 경기를 완료 기록으로 바꾸지 않습니다.

최신 상태 분리 검증: 전체 Flutter 테스트 77개 통과. 완료 기록·예정 기록·진행 중·결과 확인·팀 결과 대기를 구분하는 Mock 테스트와 기존 경기 등록 흐름 검증을 포함합니다.

## 내 매치 날짜 제한

내 매치는 한국 날짜 기준 오늘 이후만 조회·표시합니다. 오늘에서는 이전 날짜 이동을 비활성화하고 달력도 오늘부터 선택할 수 있습니다. provider에서도 과거 날짜 요청은 빈 결과로 처리하여 실제 조회를 보내지 않습니다. 지난 매치의 과거 완료 기록 조회는 유지합니다. 관련 위젯·Mock 검증을 포함한 전체 테스트 79개가 통과했습니다.

## 2026-10-29 평가 메뉴 제거

사용자 요청으로 본사의 `매니저 평가`와 매니저의 `내 평가` 메뉴를 제거했습니다. 매니저 메뉴는 `내 매치 / 지난 매치`입니다. 전용 내 평가 위젯과 매니저별 예약 화면의 평가 전용 분기도 제거했습니다. 매니저 관리의 기존 상세 정보 및 백엔드 API·DB는 유지합니다. 본사 메뉴 수에 의존하던 사이드바는 명시적인 역할 값으로 정렬·배지를 유지합니다. 전체 Flutter 테스트 79개가 통과했습니다.

## 최신 화면 구성

사용자의 새 이미지 요청에 따라 `내 매치 / 실력매칭 / 팀매칭`으로 변경했습니다. 내 매치는 오늘 이후 예정 경기, 두 매칭 화면은 각각 완료 결과입니다. 기존 날짜별 완료 매치 탭 설명은 과거 구현 상태이며, 최신 API·한계·검증은 [경기 화면 문서](manager-match-design-2026-10-29.md)를 참고합니다.
