# 관리자 디자인과 현재 API 연결

작성 일 : 2026-10-28 / 작업자 : 양태건

첨부된 전체 관리자 목업을 기준으로 기존 관리자 저장소를 보완했습니다. 회원 앱은 변경하지 않았습니다.

| 화면 | 현재 연결과 범위 |
| --- | --- |
| 로그인 | `/admin/login`, `/manager/login` 결과의 역할로 진입 |
| 대시보드 | 실제 문의·신고·이의신청·교육·팀 집계, 공지·처리할 일 |
| 매치 관리 | 담당 예약, `/match/team_match` 팀 매칭 조회, `/match/cancel` 취소 이력 |
| 품의 | 기존 품의 유형·결재자·사진 API |
| 문의·신고·이의신청 | 기존 조회·답변·심의 시작 API |
| 매니저 교육 | 기존 교육 목록·참여·이수 API |
| 회원·매니저·팀 | 실제 ID별 목록·상세 조회 |
| 구장 조회 | `/match/ground?keyword=...`, `/match/ground/{g_code}` 목록·상세 분할 배치 |
| 매니저 내 매치·지난 매치 | `/match/operations`와 서버 경기 상태, 완료 결과 |

## 이미지와 다른 항목

- 매출 현황은 등록된 매출 조회 API가 없어 구현 완료로 취급하지 않습니다. 매출·예약률·할인율을 임의 계산하지 않습니다.
- 매니저의 팀경기매치는 이전 요청대로 메뉴만 유지합니다. 본사용 전체 팀 경기 API를 매니저에게 연결하지 않습니다.
- 취소 이력은 취소 예약을 그대로 조회합니다. 운영 목록의 구장 코드 누락과 취소 예약 필터 보완은 별도 백엔드 승인 대기입니다. 취소 실행이 연결됐다고 보고하지 않습니다.
- 이미지의 예시 이름·날짜·점수·건수는 실제 API 값으로 대체하며 더미 데이터로 채우지 않습니다.

## 이번 구장 보완

공통 HTTP 서비스와 주소·인증·오류 처리를 재사용합니다. 검색 provider를 분리해 이전 검색 응답이 새 결과를 덮지 않게 하고, 세션 변경 시 검색 조건을 초기화합니다. 실제 코드로 상세를 조회하고 로딩·빈 결과·오류·재시도를 제공합니다.

검증: 전체 Flutter Mock 테스트 67개 통과. 실제 DB 쓰기·서버 실행은 하지 않았습니다. 실제 서버 및 기기에서 최종 화면 확인이 필요합니다.

## 2026-10-29 변경

새 담당 구장 일정 API를 연결하여 매니저 팀경기매치의 준비 중 안내를 실제 조회 화면으로 교체했습니다. 위의 메뉴만 유지한다는 설명은 이전 구현 상태입니다. 최신 범위와 서버 권한 제한은 [담당 구장 일정 문서](manager-schedule-2026-10-29.md)를 확인합니다.
