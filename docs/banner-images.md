# 공지 작성 창의 배너 설정

작성 일 : 2026-10-28 / 작업자 : 양태건

## 사용 방법

1. 본사 계정으로 로그인하고 공지 작성 창을 엽니다.
2. `배너 이미지 선택·등록`을 누릅니다.
3. 홍보팀 직원은 JPEG·PNG·WebP 이미지를 선택하여 미리 본 뒤 업로드하거나, 등록된 배너를 선택합니다.
4. 노출 시작일·종료일을 선택하고 `배너 적용`을 누릅니다.
5. 공지 제목·내용·대상은 기존 `공지 등록`으로 별도 저장합니다.

배너 API에는 공지 번호 연결이 없습니다. 공지를 취소하거나 닫아도 이미 업로드·적용한 배너는 유지됩니다. 이 동작을 공지 첨부파일 저장으로 설명하지 않습니다. 공지 API나 DB 구조는 수정하지 않았습니다.

## 연결 계약

- `GET /images/banner`: 등록된 이미지와 현재 노출 여부.
- `POST /images/banner`: multipart `file`, 로그인 직원의 `h_id`.
- `GET /images/banner/files/{b_image}`: 응답의 상대 `image_url`을 공통 서버 주소로 해석하여 표시.
- `POST /images/banner-select`: JSON `h_id`, `b_seq`, `c_start`, `c_end`.
- 업로드는 10MB 이하 JPEG·PNG·WebP. 실제 파일 내용과 25MP 제한은 서버가 최종 검증.
- 등록·선택 권한은 홍보팀이며 재직 여부까지 서버가 최종 검증. 화면의 부서 확인만으로 권한을 보장하지 않음.
- 선택 해제·이미지 삭제·선택 이력 조회 API는 이번 공지 작성 기능에 연결하지 않음.

목록 GET은 백엔드에서 만료된 선택 상태를 갱신합니다. 검증 과정에서는 실제 API를 호출하지 않았으며 MockClient만 사용했습니다.

## 검증

전체 Flutter 테스트 72개 통과. 배너 테스트 5개는 multipart·상대 이미지 경로·기간 선택·중복 제출·실패 후 재시도·다른 부서 제한·작성 창의 빈 목록을 확인합니다.

실제 파일 선택 창, 서버 업로드·배너 노출 및 실기기 동작은 미검증입니다. 실제 DB에 접근하거나 서버를 실행하지 않았습니다.
